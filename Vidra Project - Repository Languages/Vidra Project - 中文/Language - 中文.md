<a name=what-is-boxvidra></a>
- **什么是BoxVidra模拟器?**

**`BoxVidra是一款现代PC模拟器，以其独特的概念脱颖而出，完全满足您的需求，仿佛在手机上操作真实的计算机。您可以玩游戏、工作、格式化，体验并享受Windows或macOS在手机上的体验。它也被认为是Xfce开发中的巨大飞跃，包含了全新独特的开发，完美复刻其他操作系统的体验。因此，如果您想在手机上获得完整的计算机体验，您来对地方了。`**

- **每种模式有什么区别?**

<a name=desktop-mode></a> **`BoxVidra模拟器有三种模式，基本模式是桌面模式：`** 该模式允许用户使用多种系统结构，最重要的是Windows 10、Windows 11、Windows 7，并允许用户运行更多程序，如网页浏览器、文本编辑器、社交媒体程序、视频播放等，还允许用户完整真实地体验所选系统结构。此外，我们在xfce4桌面系统上提供了一个全新且不同的开发环境。

<a name=application-mode></a> **`第二种也是最重要的模式是应用模式：`** 该模式以完全不同的全新方式工作，其理念是同类中的新理念。我们为用户提供了一个完整集成的应用程序系统结构，像一个实际程序一样工作，唯一的区别是您从Termux运行它，之后所有通过应用程序UI的操作都在x11中显示，就像使用真实程序一样。它还支持容器功能，无任何问题，具有许多优势。

<a name=tiny-mode></a> **`第三种也是最后一种模式是精简模式：`** 更快更稳定，允许用户仅使用Linux程序，因此用户在此模式下完全无法使用wine服务。

- **如何安装BoxVidra?**

**`只需一条命令，粘贴到Termux中，整个安装过程将自动开始，无需用户干预。安装过程根据网络速度从10分钟到30分钟不等。`**

<a name=what-is-xboxvidra></a>
- **什么是XboxVidra模拟器?**

**`XboxVidra是第一款在Termux上发布的Xbox模拟器，具有许多优势，如类似Xbox的用户界面、音效等。您可以在那里玩任何游戏，无需担心性能问题，所有设备（无论是骁龙还是Mali）都能获得强大稳定的性能。简而言之，如果您想在手机上获得真实的Xbox体验，您来对地方了。`**

- **每种模式有什么区别?**

<a name=xboxvidra-full-emulator></a> **`XboxVidra模拟器有两种模式，基本模式是模拟器结构模式：`** 这是一个基本模式，模拟器通过运行命令轻松启动，该模式用作实际模拟器，远离任何其他内容，是一个完整的Xbox软件，具有Xbox用户界面及其所有内容、设置和配件，性能和稳定性优于基于BoxVidra模拟器的第二种模式。

<a name=xboxvidra-basedon-mode></a> **`第二种模式基于BoxVidra模拟器：`** 该模式以完全不同的方式工作，严格来说它不算一种模式，因为它作为BoxVidra模拟器中的一个独立软件存在，使用户能够在BoxVidra模拟器上运行Xbox游戏，类似于现代Windows系统（如Windows 10和Windows 11），性能略低但服务完整，稳定性极佳。

- **如何安装XboxVidra?**

**`只需一条命令，粘贴到Termux中，整个安装过程将自动开始，无需用户干预。安装过程根据网络速度从5分钟到20分钟不等。`**
