<a name=what-is-boxvidra></a>
- **מה זה בוקסוידרה אמולטור?**

**`בוקסוידרה הוא אמולטור PC מודרני, ייחודי מסוגו, עם קונספט חדש לגמרי, שמספק לך חווית מחשב אמיתית בטלפון, אתה יכול לשחק, לעבוד, לפרמט, להתנסות, וליהנות מהחוויה של Windows או macOS בטלפון שלך. זה גם נחשב לקפיצה גדולה מאוד בפיתוח של Xfce, כי הוא כולל פיתוחים חדשים וייחודיים שמחקים את מערכות ההפעלה האלו בצורה זהה. אם אתה רוצה את חווית המחשב המלאה – אתה במקום הנכון.`**

- **מה ההבדל בין המצבים?**

<a name=desktop-mode></a> **`יש לנו שלושה מצבים לבוקסוידרה אמולטור, והמצב הבסיסי הוא מצב שולחן העבודה:`** מצב זה מאפשר למשתמש להפעיל מבני מערכת שונים, החשובים ביותר הם Windows 10, Windows 11, Windows 7, ומאפשר להריץ דפדפנים, עורכי טקסט, תוכנות מדיה, ועוד. הוא מספק חוויה מלאה ומציאותית של מערכת ההפעלה שנבחרה, וכולל גם סביבת פיתוח חדשה לחלוטין על בסיס xfce4.

<a name=application-mode></a> **`המצב השני והחשוב ביותר הוא מצב אפליקציה:`** מצב זה פועל בצורה שונה וחדשה לגמרי, ומספק מבנה מערכת אפליקציה שלם שפועל כמו תוכנה אמיתית, ההבדל היחיד הוא שאתה מריץ אותו מתוך תרמוקס (**טרמוקס**), ולאחר מכן כל מה שנעשה דרך ממשק האפליקציה מוצג דרך x11 (**אקס 11**), כאילו אתה משתמש בתוכנה אמיתית. המצב תומך גם ב־**קונטיינרים** ללא בעיות, עם יתרונות רבים.

<a name=tiny-mode></a> **`המצב השלישי והאחרון הוא מצב זעיר:`** שהוא מהיר יותר ויציב יותר, ומאפשר רק שימוש בתוכנות לינוקס. לא ניתן להשתמש בכלל בשירות **Wine** (**וויין**) במצב הזה.

- **איך מתקינים את בוקסוידרה?**

**`רק פקודה אחת, תדביק אותה בתוך טרמוקס (**Termux**), וכל תהליך ההתקנה יתחיל באופן אוטומטי, בלי צורך בהתערבות משתמש. ההתקנה לוקחת בין 10 ל־30 דקות, תלוי במהירות האינטרנט.`**

<a name=what-is-xboxvidra></a>
- **מהו אמולטור אקסבוקסווידרה?**

**`אקסבוקסווידרה הוא אמולטור האקסבוקס הראשון שיצא לשוק על טרמוקס, והוא מציע יתרונות רבים כגון ממשק משתמש בדמות אקסבוקס, אפקטי קול וכו'. ניתן לשחק כל משחק שתבחר ללא בעיות, עם ביצועים חזקים ויציבים לכל המכשירים, בין אם מדובר ב-Snapdragon או ב-Mali. בקיצור... אם ברצונך לחוות את האקסבוקס האמיתי בטלפון שלך, הגעת למקום הנכון.`**

- **מה ההבדל בין כל מצב?**

<a name=xboxvidra-full-emulator></a> **`ובכן, יש לנו שני מצבים לאמולטור אקסבוקסווידרה, כאשר המצב הבסיסי הוא מצב מבנה האמולטור:`**  
זהו מצב בסיסי, בו האמולטור מופעל באמצעות פקודת הרצה בקלות, ומצב זה משמש כאמולטור ממשי – תוכנת אקסבוקס מלאה עם ממשק משתמש כמו אקסבוקס, עם כל התכנים, ההגדרות והאביזרים, ובביצועים ויציבות טובים יותר מהמצב השני המבוסס על אמולטור בוקסווידרה כתוכנה נפרדת להפעלת משחקי אקסבוקס.

<a name=xboxvidra-basedon-mode></a> **`המצב השני מבוסס על אמולטור בוקסווידרה:`**  
מצב זה פועל באופן שונה לחלוטין, ואינו נחשב למצב במובן הקלאסי, אלא מופיע כתוכנה נפרדת בתוך אמולטור בוקסווידרה, המעניק למשתמש את היכולת להריץ משחקי אקסבוקס על אמולטור בוקסווידרה, בדומה למערכות Windows מודרניות כגון Windows 10 ו-Windows 11, עם ביצועים מעט נמוכים יותר אך עם שירותים מלאים ויציבות מוחלטת.

- **איך להתקין את אקסבוקסווידרה?**

**`בעזרת פקודה אחת בלבד, תדביק אותה בטרמוקס, ולאחר מכן תתחיל תהליך התקנה מלא ללא כל התערבות משתמש. תהליך ההתקנה נמשך בין 5 ל-20 דקות, בהתאם למהירות האינטרנט.`**
