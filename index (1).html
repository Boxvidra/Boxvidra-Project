About

ده مشروع HTML واحد مربوط بـ Firebase Auth و Realtime Database. التصميم Fluent UI متدرج أحمر على أسود، والواجهة RTL.

لو حبيت بعدين نضيف صفحات حقيقية متعددة أو لوحة Admin أو Payments، البنية الحالية جاهزة.
